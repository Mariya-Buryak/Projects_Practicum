# Projects_Practicum

Данный проект был выполнен в ходе обучения в Яндекс.Практикуме, профессия - "Аналитик данных"

### Тема проекта: «Анализ бизнес-показателей развлекательного приложения Procrastinate Pro+»

#### Краткое описание проекта

**Заказчик исследования** — отдел маркетинга компании, владеющей развлекательным приложением Procrastinate Pro+.

**Цель исследования**: помочь заказчикам разобраться в причинах убытков при огромных вложениях на рекламу, чтобы компания вышла в плюс.

Для достижения поставленной цели необходимо будет **изучить**:

- откуда приходят пользователи и какими устройствами они пользуются,
- сколько стоит привлечение пользователей из различных рекламных каналов;
- сколько денег приносит каждый клиент,
- когда расходы на привлечение клиента окупаются,
- какие факторы мешают привлечению клиентов.

*Примечание*:

Есть данные о пользователях, привлечённых с 1 мая по 27 октября 2019 года:
- лог сервера с данными об их посещениях;
- выгрузка их покупок за этот период;
- рекламные расходы.

Работа будет выполнена в **6 этапов**:

1. Загрузка данных и подготовка их к анализу
2. Определение функций для дальнейшего анализа
3. Исследовательский анализ данных
4. Маркетинг
5. Оценка окупаемости рекламы
6. Формирование общего вывода и рекомендаций


**Используемые библиотеки** :
- pandas;
- matplotlib;
- seaborn;
- numpy.
