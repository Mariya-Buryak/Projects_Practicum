# Анализ вакансий Системного аналитика и Аналитика данных по данным HH.ru

Самостоятельный проект, профессия "Аналитик данных".

**Заказчик исследования**: Заказчика нет, анализ вакансий проводился с целью формирования рекомендаций для работодателя и соискателя.

**Цель проекта**: Выявить различия в предлагаемых вакансиях для Аналитиков данных и Системных аналитиков.

Для достижения поставленной цели были выполнены следующие задачи:

- изучен рынок вакансий для Аналитиков данных и Системных аналитиков согласно данным из HH.ru;
- определены самые востребованные кандидаты в разрезе грейдов и типичного места работы/работодателя;
- сформировать выводы и рекомендации.
- 
Таким образом, исследование прошло в **четыре этапа**:

1. Загрузка данных и подготовка их к анализу
2. Предобработка данных
3. Исследовательский анализ данных
4. Формирование общих выводов и рекомендаций
