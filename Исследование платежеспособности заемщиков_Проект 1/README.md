# Projects_Practicum

Данный проект был выполнен в ходе обучения в Яндекс.Практикуме, профессия - "Аналитик данных Plus"

### Название проекта: «Исследование надежности клиентов»

#### Описание проекта

**Клиент** — кредитный отдел банка.   
**Входные данные от банка** — статистика о платежеспособности клиентов.   
**Цель исследования** — просмотреть изображения семейного положения, уровня дохода и количества детей-клиентов на момент погашения кредита в установленном законом порядке.   

**Используемые библиотеки** : pandas
