# Projects_Practicum

Данный проект был выполнен в ходе обучения в Яндекс.Практикуме, профессия - "Аналитик данных"

### Тема проекта: «Исследование объявлений о продаже квартирв»

#### Краткое описание проекта

**Входные данные** — данные сервиса Яндекс Недвижимость — архив объявлений о продаже квартир в Санкт-Петербурге и соседних населённых пунктах за несколько лет.
**Цель исследования** — научиться определять рыночную стоимость объектов недвижимости.
**Задачи исследования** - проведение исследовательского анализ данных и установка параметров, влияющих на цену объектов, что позволит построить автоматизированную систему, отслеживающую аномалии и мошенническую деятельность. 

**Используемые библиотеки** :
- pandas;
- matplotlib.pyplot;
- seaborn;
- numpy.
