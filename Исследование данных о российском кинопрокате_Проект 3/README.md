# Projects_Practicum

Данный проект был выполнен в ходе обучения в Яндекс.Практикуме, профессия - "Аналитик данных"

### Тема сборного проекта: «Исследование данных о российском кинопрокате»

#### Краткое описание проекта

**Заказчик исследования**: Министерство культуры Российской Федерации.   

**Цель исследования**: выявить текущие тренды рынка российского кинопроката.   

Для достижения поставленной цели было необходимо выполнить следующие задачи:

- изучить рынок российского кинопроката;
- уделить внимание фильмам, которые получили государственную поддержку;
- попробовать ответить на вопрос, насколько такие фильмы интересны зрителю.

**Примечание**:

*Работа  проведена на основании данных, опубликованных на портале открытых данных Министерства культуры. Набор данных содержит информацию о прокатных удостоверениях, сборах и государственной поддержке фильмов, а также информацию с сайта КиноПоиск**.

**Используемые библиотеки** :
- pandas;
- matplotlib.pyplot;
- seaborn;
- numpy;
- re.
